Long Game is a personal web application for researching investments, recording portfolio activity, and planning regular contributions.

## How it works

- A transaction ledger tracks deposits, fees, investment income, and gains separately.
- A deterministic calculator checks cash, trading costs, allocation limits, and the evidence reviewed for a potential purchase.
- Scheduled research records source changes and data gaps for later review.
